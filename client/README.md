# Newstrade Flutter client

One Dart codebase for Windows and Android. It talks only to the backend API;
exchange keys never reach this client.

## Generate the platform folders

Platform scaffolding (android/, windows/, etc.) is generated by Flutter, not
committed. Run once after cloning:

```bash
cd client
flutter create --platforms=android,windows .
flutter pub get
```

## Run

Desktop (Windows):

```bash
flutter run -d windows --dart-define=API_BASE_URL=http://localhost:8080
```

Android:

```bash
flutter run -d android --dart-define=API_BASE_URL=http://10.0.2.2:8080
```

Set the API token and backend URL in the Settings screen; they are stored with
`shared_preferences`.

## Build

```bash
flutter build windows
flutter build apk --release
```

## Structure

- `lib/models.dart` - API models with tolerant JSON parsing.
- `lib/services/api_client.dart` - REST client with bearer auth.
- `lib/services/ws_service.dart` - reconnecting WebSocket for live push.
- `lib/state/app_state.dart` - settings, health, and kill-switch state.
- `lib/screens/` - news, signals, portfolio, channels, settings.
- `lib/widgets/` - confidence bar, direction badge, signal card, news tile.

## Notifications

Android uses FCM (add `google-services.json` when wiring it up). Windows has no
official FCM support, so the desktop build raises in-app and toast
notifications from `ws_service.dart`.
